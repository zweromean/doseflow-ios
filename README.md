# 복약 — iPhone SwiftUI 앱

첨부 프로토타입을 기준으로 구현한 iOS 17+ 앱입니다. 밝은 회색 카드, 파랑 버튼, 구간별 약효 그래프, 기분 선택, 용량 선택 시트, 캘린더와 기능 소개 화면을 포함합니다.

## Mac에서 실행

1. Xcode 15 이상과 XcodeGen을 설치합니다: `brew install xcodegen`
2. 이 디렉터리에서 `xcodegen generate`를 실행합니다.
3. 생성된 `DoseFlow.xcodeproj`를 엽니다.
4. 앱과 위젯 타깃의 Signing에서 자신의 Apple 개발팀을 선택합니다.
5. `com.example` 번들 ID와 `group.com.example.DoseFlow` App Group을 자신의 고유 ID로 변경합니다. `project.yml`과 `Shared/MedicationActivity.swift`의 suite를 동일하게 변경하고 프로젝트를 다시 생성합니다. Developer 계정에서 해당 App Group을 두 타깃에 등록합니다.
6. iPhone 시뮬레이터 또는 실기기를 선택하고 실행합니다.

## 구현

- 복약 용량 선택(18/27/36/45/54mg), 현재 시간으로 기록, 삭제 및 로컬 저장
- 최근 복약의 예상 그래프, 드래그 시간 커서, 구간 조정
- 날짜별 기분과 메모, 월간 캘린더, 목표/할 일 관리
- HealthKit에서 실제 심박 및 수면 읽기, 복용 후 16시간 심박 차트
- 날짜 범위별 실제 복용·메모·심박·수면 요약을 PDF로 생성하고 공유
- 매일 복용 알림 등록 및 해제
- 홈 화면 위젯, 잠금화면 Live Activity 및 Dynamic Island 확장
- 설정에서 기능 소개 슬라이드와 Live Activity 시작

빈 기록으로 시작합니다. 홈의 ‘지금 복용’을 누르고 저장하면 그래프가 나타납니다. 사용자 데이터는 UserDefaults 및 공유 App Group에 저장됩니다. 위젯은 홈 화면 편집 메뉴에서 추가합니다.

## 검증 및 남은 범위

이 작업 환경은 Linux이며 Swift/Xcode/iOS SDK가 없어 컴파일, 시뮬레이터, 실기기 검증은 수행하지 못했습니다. Xcode에서 빌드한 뒤 기기별 레이아웃과 서명, 알림 및 Live Activity를 확인해야 합니다.

알약 이미지는 원본 에셋이 제공되지 않아 SwiftUI 도형으로 재현했습니다. HealthKit 심박·수면 읽기 연동을 포함합니다. 개인 반응 예측 모델은 포함하지 않습니다. PDF에는 실제 입력한 기록만 포함됩니다. 그래프 모양은 참고용 시각화로, 임상 약동학 모델이 아닙니다. 구간 조정은 색상 구간을 변경합니다. 위젯은 앱에서 설정한 예상 종료 구간을 공유합니다. 앱 아이콘과 App Store 배포 설정은 포함하지 않았습니다.


## HealthKit 설정 및 검증

- 앱 타깃에만 HealthKit entitlement와 읽기 목적 문구가 설정되어 있습니다. XcodeGen으로 재생성하고 Signing & Capabilities에서 HealthKit을 확인하세요. 개발자 계정의 App ID에서도 HealthKit을 활성화해야 합니다.
- 앱 설정 → 건강 앱 연결에서 심박과 수면 읽기 권한을 요청합니다. 쓰기 권한, 백그라운드 수집, 서버 업로드는 사용하지 않습니다. 위젯에는 건강 데이터를 공유하지 않습니다.
- 읽기 권한 허용 여부는 HealthKit 정책상 앱에서 판별할 수 없습니다. 빈 결과를 권한 거절로 단정하지 않으며, 측정값이 없는 경우 ‘데이터 없음’으로 표시합니다. 권한 변경 후 앱으로 돌아오거나 새로고침하면 다시 조회합니다.
- 수면은 asleepUnspecified/Core/Deep/REM만 포함하고 inBed/awake는 제외합니다. 겹치는 구간을 합쳐 여러 소스의 중복을 제거합니다. 각 날짜에 전날 정오~당일 정오 수면을 배정하고, 기록이 있는 날만 평균을 계산합니다. 이는 건강 앱의 소스 우선순위 방식과 차이가 있을 수 있습니다.
- 심박 평균은 조회된 샘플의 산술평균입니다. Apple Watch의 측정 간격을 보간하거나 실시간 측정으로 표시하지 않습니다.
- 실기기 확인: 권한 허용/미허용/일부 허용, 빈 건강 기록, 건강 앱 수동 심박·수면 입력, 자정에 걸친 수면, 겹치는 수면 기록, 날짜 범위 변경, PDF 공유를 확인하세요. 수면 기록만 허용해도 심박 없이 수면이 표시되어야 합니다.
- Linux 환경에서 iOS SDK 기반 컴파일과 HealthKit 권한 창·실기기 조회는 검증하지 못했습니다.


## 추가 선택 시트와 루틴

약 종류 선택 시트에 콘서타·메디키넷·아토목세틴·페니드·기타가 표시됩니다. 콘서타에는 첨부된 용량 목록을 제공하며 다른 약은 처방 용량을 직접 입력합니다(현재 정수 mg). 기타는 약 이름을 입력할 수 있습니다. 기록·캘린더·PDF·위젯에 약 이름을 유지하며 이전 기록은 콘서타로 읽습니다. 약별 예상 모델은 추가하지 않았으므로 콘서타 이외 기록에는 예상 곡선/Live Activity를 적용하지 않습니다.

복용 루틴 만들기에서 아침·점심·저녁에 약을 추가하거나 편집하고 새 루틴을 만들 수 있습니다. 상단 저장을 누르면 반영되며 닫으면 초안을 폐기합니다. 저장한 루틴은 홈에 표시됩니다. 루틴은 복약을 자동 기록하거나 알림을 자동 등록하지 않습니다. 매일 알림은 기존 설정 → 복용 알림에서 별도로 관리합니다.

시트는 시스템 흐림·안전 영역을 사용합니다. 첨부 이미지 속 시각·통신·배터리는 앱 UI로 만들지 않았습니다. 원본 알약 사진 에셋이 없어 도형을 유지하며 Xcode/실기기 화면 검증이 필요합니다. 마이그레이션·루틴 저장 XCTest를 추가했지만 이 환경에서 실행하지 못했습니다.
